# Concurrency & Parallelism Demo

โปรแกรมนี้เขียนขึ้นเพื่อทดสอบการทำงานพร้อมกัน (Concurrency และ Parallelism) ในภาษา Python โดยแบ่งการทำงานออกเป็น 3 รูปแบบ เพื่อให้เห็นความเหมาะสมในการใช้งานแต่ละสถานการณ์

## รูปแบบที่ใช้ทดสอบ

1. **Asyncio (`asyncio`)**
   - **จำลองงาน:** การดาวน์โหลดไฟล์ชีทเรียนผ่านอินเทอร์เน็ต
   - **อธิบาย:** เหมาะกับงานที่ต้อง "รอ" (I/O Bound) โปรแกรมจะสลับไปทำงานอื่นระหว่างที่รอข้อมูล โดยทำงานอยู่บน Thread เดียว

2. **Threading (`threading`)**
   - **จำลองงาน:** การสั่งปรินต์เอกสาร
   - **อธิบาย:** เหมาะกับงาน I/O Bound เช่นกัน โดยระบบจะสร้าง Thread ย่อยขึ้นมาเพื่อทำงานซ้อนทับกัน ช่วยให้ไม่ต้องรอปรินต์งานทีละแผ่น

3. **Process Pool (`multiprocessing`)**
   - **จำลองงาน:** การให้คอมพิวเตอร์คำนวณสมการทางคณิตศาสตร์ที่ซับซ้อน (CPU Bound)
   - **อธิบาย:** ทำการแตก Process ใหม่แยกขาดจากกัน ทำให้สามารถใช้งาน CPU หลาย Core พร้อมกันได้อย่างแท้จริง (Parallelism) และหลบข้อจำกัดเรื่อง GIL ของ Python ได้
